Olist E-commerce Analytics
An end-to-end e-commerce analytics project using Excel, SQL, Tableau and Power BI to analyze sales performance, customer reviews, payments, delivery performance and product categories.
Tools: Excel, Power Query, MySQL, Tableau, Power BI
Key Analysis:
1. Sales and order performance
2. Customer review analysis
3. Payment method analysis
4. Delivery time analysis
5. Product/category performance
6. Customer and geographic analysis
Project Workflow:
1. Data collection
2. Data cleaning using Power Query
3. SQL data analysis
4. Tableau visualization
5. Power BI dashboard
6. Business insights and recommendations
